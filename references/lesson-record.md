# 经验记录接口

轻量检查与完整复盘复用项目现有记录。通用协议的唯一真源是已安装 `asm` checkout 的 `modules/make/references/lesson-lifecycle.md`：需要读取、晋升、合并或撤销规则时 load `asm` skill 并读取该文。本技能整理事件与观察，不另建中央日志或自动晋升器。

每项至少给出一句话教训、适用范围、独立事件与版本证据、影响、原因/假设、修复及验证、正确案例（无则说明）、复发计数、目标位置和状态。证据使用项目相对引用，保留原事件；同一次失败的多个报告不重复计数。

阶段二选定改进后，记录以下三个独立结论：

- implemented：相关内容或机制已修改，给出版本与位置。
- regression_verified：原失败场景已验证，给出真实方法、结果及未运行检查。
- observing：未来何种同类任务读取、观察什么、何时复核或撤销；缺后续证据时不声称长期收益。

示例观察条件：“下次同类接入缺陷先检查报告人的实际客户端；记录是否复现同样配置并完成该界面验证。”这是观察计划，不能写成已经降低返工。受保护范围或范围外改进保持未实施；正确实践同样记录证据和适用条件。
